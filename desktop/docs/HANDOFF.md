# FocusDuo Desktop — текущая передача

## Статус на 10 октября 2026

**Этап 1 из 10 завершён:** самостоятельная сборка, JDK 21, дизайн-система и запускаемый стартовый демоэкран. Следующий этап — `FakeRepository`, комната и задачи. [План всей desktop-части](ROADMAP.md) разбит на этапы ориентировочно по 25–40 минут, без автоматического перехода к следующему этапу в одном рабочем заходе.

## Что работает

- Kotlin/JVM 2.2.20, Compose Desktop 1.9.1, Gradle Wrapper 8.13 с SHA-256 дистрибутива, Java toolchain 21.
- PowerShell-скрипт `desktop/run.ps1` находит JDK 21 и не меняет постоянные системные настройки. Здесь использован уже установленный Corretto 21.0.6 из пользовательской `.jdks`.
- Светло-зелёные компоненты Compose, Manrope с кириллицей и отдельными начертаниями, согласованные Canvas-иконки и логотип.
- Стартовый экран без автоматического включения демо. `--demo` или кнопка «Открыть деморежим» явно включают демо, отмеченное в заголовке окна и интерфейсе.
- Локальная форма имени и цели: предпросмотр при вводе, сохранение в памяти, отмена несохранённых правок, валидация имени 2–40 и цели до 240 символов.
- Клавиатурный переход Tab / Shift+Tab из полей; проверена последовательность Tab → Enter для сохранения. Enter внутри многострочной цели остаётся переносом строки.
- Системная рамка Windows; проверены разворачивание, восстановление и закрытие окна. Адаптация формы к одной/двум колонкам и вертикальная прокрутка.

## Решения и границы

Рабочая ветка: `feat/desktop-mvp`, создана от `main` с backend MVP (коммит `462b827`). Изменения только внутри `desktop/**`. Backend и общие файлы не менялись. Commit, push, merge и publish в этом этапе не выполнялись.

Окончательный дизайн — последний прикреплённый пользователем светло-зелёный макет с круговым таймером: [копия](design/light-green-reference.png). Он заменяет прежнюю тёмную тему из общего ТЗ и `docs/design/`. Контракт API V1 сохраняется без изменений. Полные справочные копии ТЗ и контракта находятся в `desktop/docs/reference/`.

## Проверенные команды

Из корня репозитория, PowerShell:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\desktop\run.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\desktop\run.ps1 -Demo
powershell -NoProfile -ExecutionPolicy Bypass -File .\desktop\run.ps1 -Demo -Width 1000 -Height 700
```

Сборка и тесты из `desktop/` с `JAVA_HOME`, указывающим на JDK 21:

```powershell
.\gradlew.bat test --console=plain
```

Результат последнего прогона: **BUILD SUCCESSFUL, 5 тестов, 0 failures, 0 errors, 0 skipped**. Проверены отсутствие автоматического демо, явный флаг, ошибочные аргументы/размеры окна, размер для QA и отдельный режим справки. Отчёт: `desktop/build/reports/tests/test/index.html`; XML: `desktop/build/test-results/test/TEST-dev.focusduo.LaunchOptionsTest.xml`.

Сборка wrapper выполнена Gradle 8.13 на JDK 21. Последующие сборки и запуски используют собственный `desktop/gradlew.bat`. `git diff --check` проверен после исправления пробела в тексте лицензии.

## Точные ограничения

1. Это стартовый экран первого этапа, **не полноценный рабочий деморежим комнаты**. `FakeRepository`, состояние двух участников и задачи ещё не реализованы.
2. Таймер, пауза/продолжение раунда, BREAK, итог, история, вход/регистрация и настройки ещё не реализованы.
3. Нет `RealRepository`, Ktor, REST/WS, авторизации и reconnect. Сеть не используется; ошибка сети не может переключить режим. Будущий default сервера — `http://127.0.0.1:8090`.
4. Имя и цель хранятся только в памяти и исчезают при закрытии приложения; это локальная демонстрационная форма, а не сохранение профиля на сервере.
5. Пять текущих тестов проверяют только запуск/аргументы. Контрактные fixtures, таймер, HTTP/WS и интеграция с Java ещё не проверялись клиентом.
6. Проверены только реализованные стартовые экраны. Полный аудит доступности, все ошибки и экраны будущего приложения остаются в плане. Системное окно не повторяет кастомную рамку макета.
7. `.msi`/`.exe` и подписанный установщик ещё не собраны; упаковка относится к этапу 10. Bash-команды в README пока не проверялись на Linux/macOS.

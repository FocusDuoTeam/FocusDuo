# Первый PR backend

Репозиторий: [KDvibers/FocusDuo](https://github.com/KDvibers/FocusDuo). Ветка: `feat/backend-mvp` → `main`. Открыть PR после того, как владелец отправит локальные коммиты через push.

## Заголовок

Реализовать Java backend MVP по контракту FocusDuo v1

## Описание

Добавляет сервер для совместных рабочих сессий двух пользователей. Два пользователя могут зарегистрироваться, создать общую комнату, начать раунд, менять свои задачи и получить сохранённый результат. REST `/api/v1` и raw JSON WebSocket `/ws/rooms/{roomId}` используют согласованный контракт v1; локальный адрес — `http://127.0.0.1:8090`.

- Авторизация непрозрачными bearer-сессиями, хеширование паролей/токенов, проверка прав, logout и закрытие сокетов истёкшей/отозванной сессии.
- Комнаты на двоих, настройки владельца, личные цели/задачи, пауза, продолжение, ручное и автоматическое завершение, отдельный BREAK и закрытие комнаты любым участником.
- PostgreSQL/Flyway, сохраняемый таймер, неизменяемая история, блокировки и ограничения БД, revision и атомарные результаты Idempotency-Key; WebSocket публикует полные снимки после commit.
- Java 21, Spring Boot, собственный Maven Wrapper, Compose для PostgreSQL 17, backend CI, OpenAPI, примеры запросов и инструкции запуска/передачи Kotlin-разработчику. `desktop/` не изменяется.

## Проверки

На Windows с Java 21 выполнен `mvnw.cmd verify`: **40 passed, 0 failures, 0 errors, 0 skipped**. 27 unit/auth/fixture/timer-тестов; 13 интеграционных (`BackendIT`: 6, `DomainPersistenceIT`: 6, `RestartIT`: 1) на отдельном нативном PostgreSQL 17.11, `127.0.0.1:55434`, через `FOCUSDUO_TEST_DB_*`.

Покрыты HTTP/WS-сценарий двух пользователей, таймер с управляемыми часами, reconnect, авторизация и срок сессии, неизменность истории, конкурирующие команды/членства и идемпотентные повторы. Восстановление проверено закрытием и повторным созданием Spring-контекста с той же БД. OpenAPI прошёл официальную метасхему 3.1; все 10 исходных fixtures соответствуют DTO-схемам. YAML Compose/CI разобран.

Собранный JAR отдельно запущен на `127.0.0.1:8090`: HTTP-сценарий register двух пользователей → create/join → FOCUS → создание/отметка задачи → pause/resume → finish/history → close → logout прошёл успешно.

## Ограничения проверки

Docker на локальной машине отсутствует: Compose и стандартный Testcontainers-путь не запускались. Удалённый CI, совместная работа с Kotlin-клиентом и межкомпьютерная интеграция пока не проверены. Эти проверки и исправления по review входят в следующие этапы [ROADMAP.md](ROADMAP.md).

MVP рассчитан на один процесс backend; распределённая доставка WS-событий, production TLS deployment и возможности за пределами контракта v1 не добавлены. Инструкции подключения и ограничения перечислены в [HANDOFF.md](HANDOFF.md).

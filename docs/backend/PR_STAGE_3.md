## Заголовок

## Описание

Перед подключением desktop-клиента backend получает воспроизводимую проверку двух WebSocket-сессий против отдельного JAR и инструкцию совместной приёмки. CI после Maven `verify` и HTTP smoke запускает Java 21 WS smoke: два пользователя получают полные снимки, видят изменения задач, восстанавливаются после разрыва и корректно обрабатывают logout и закрытие комнаты.

- `WebSocketSmoke.java` использует стандартные Java HTTP/WS-клиенты и существующие зависимости Jackson. Проверяет stale revision → `409`, logout → `4401` только для отозванной сессии и CLOSED snapshot перед close code 1000. Создаёт собственные тестовые аккаунты; пароли и токены не выводятся. При сбое пытается закрыть свои ресурсы, ограничивая время ожидания.
- `init-local.ps1` создаёт `.env` из примера со случайным паролем БД, сохраняя существующий файл. Совместим с Windows PowerShell 5.1 и PowerShell 7. Сам `.env` исключён из Git.
- Документация описывает первый сетевой сценарий для Kotlin, повтор команд с исходными заголовками, восстановление соединения, конфликты, таймер и историю, перезапуск сервера и совместную работу двух ПК. Таблица приёмки явно оставляет непроверенные клиентские сценарии открытыми.

Production-код, зависимости backend, согласованный контракт, исходные fixtures и `desktop/` не изменены.
